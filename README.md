# 🍲 Казан-Мастер — Умный конструктор каш из круп и бобовых

Приложение для любителей плотных, насыщенных каш в казане из различных злаков и бобовых. Решает главную проблему: **разное время варки круп и разный объем воды**, автоматически рассчитывая ступенчатую закладку и точные граммовки.

---

## 🚀 Как запустить приложение

### Вариант 1 (Быстрый запуск в Windows):
Просто дважды кликните по файлу **`start.bat`** в папке проекта. Откроется браузер по адресу `http://localhost:5173`.

### Вариант 2 (Через терминал):
```bash
npm run dev
```
И откройте в браузере: `http://localhost:5173`

## ✨ Основной функционал

1. **База всех ключевых круп и бобовых**:
   * **Гречка** (20 мин, вода $1 : 2.0$)
   * **Нут** (50 мин, вода $1 : 2.5$, предварительное замачивание 8 ч)
   * **Красная фасоль** (55 мин, вода $1 : 2.5$, предварительное замачивание 8 ч)
   * **Перловка** (45 мин, вода $1 : 2.8$, замачивание 1 ч)
   * **Красная чечевица** (15 мин, вода $1 : 2.0$, без замачивания)
   * **Рис** (20 мин, вода $1 : 2.0$)
   * **Кукурузная крупа** (25 мин, вода $1 : 3.2$)
   * **Горох колотый** (40 мин, вода $1 : 2.5$, замачивание 2 ч)
   * **Пшенка** (20 мин, вода $1 : 2.5$, ошпаривание кипятком от горечи)
   * *А также*: булгур, зеленая чечевица, маш, киноа, полба и возможность добавить **любые свои крупы**.

2. **Белковые основы**:
   * Фарш (говяжий / домашний), куриное бедро, филе грудки, индейка, говядина соломкой, свинина, грибы (для постного варианта) + кнопка добавления своего мяса.

3. **Комбинации круп**:
   * Выбор от 1 до 4 круп вручную.
   * 🎲 **«Случайный микс»** — подбирает случайное сочетание 2–4 круп.
   * ⚡ **«Быстрый микс»** — крупы со временем варки до 20 минут (варятся синхронно).
   * 🫘 **«Сытный богатырский»** — плотные крупы и бобовые.

4. **Точный расчет и ступенчатая закладка (Timeline)**:
   * Автоматический пересчет граммовок круп, мяса, овощей (лук, морковь, чеснок, томатная паста) и специй по количеству порций.
   * Ступенчатый тайминг: приложение рассчитывает, в какую минуту какую крупу засыпать и сколько кипятка долить, чтобы к концу варки все крупы приготовились одновременно!
   * Предупреждения о замачивании бобовых.

5. **Интерактивный помощник на кухне с таймером**:
   * Большой экран для готовки с крупным таймером обратного отсчета для каждого этапа.
   * Звуковой сигнал (веб-аудио) по окончании каждого шага, чтобы не пропустить закладку крупы.
   * Финальное конфетти и фанфары по завершении упревания каши!

6. **Шпаргалка и управление базой**:
   * Таблица всех коэффициентов и времени варки.
   * Сохранение всех добавленных круп в память браузера (`localStorage`).
   * Кнопка копирования рецепта в Telegram / WhatsApp.
